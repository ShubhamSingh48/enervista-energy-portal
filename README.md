# EnerVista Energy Portal - Screening Assignment

A secure, responsive, and premium consumer energy portal built with a Node.js/Express backend and HTML/Tailwind CSS frontend for Trisynex Technologies.

## 🚀 Tech Stack
- **Frontend:** HTML5, Tailwind CSS, JavaScript (Vanilla JS)
- **Backend:** Node.js, Express.js
- **Security & Features:** JWT (JSON Web Tokens) Authentication, Request Rate-Limiting, Eco-Tier Utility Greeting Module.
